# Console RPG Engine

Текстовая консольная RPG-игра на C#, разработанная с использованием фундаментальных принципов ООП и паттернов проектирования.

## 🎮 Основные возможности

* **Игровой цикл (State Machine):** Бесшовный переход между Хабом (городом), Подземельем (данжем) и Магазином с сохранением прогресса героя.
* **Боевая система:** Пошаговые сражения с противниками, генерация комнат и случайные награды из легендарных сундуков.
* **Экономика и Торговля:** Динамическое обновление витрины магазина, покупка и продажа предметов, управление золотом.
* **Инвентарь и Экипировка:** Различные типы предметов с характеристиками (оружие, броня с разбивкой по слотам, зелья исцеления).

## 🛠 Архитектура и ООП

* **Наследование и Полиморфизм:** Базовый абстрактный класс `Item`, от которого наследуются `Weapon`, `Armor` и `HealthPotion`.
* **Паттерн Фабрика (`Factory`):** Использование `EnemyFactory` для изолированной генерации врагов.
* **Композиция:** Управление списками предметов в классах `Hero` и `Store`.
* **Переопределение методов:** `ToString()` для информативного вывода статов и описания предметов в консоли.
